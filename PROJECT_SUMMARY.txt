RESEARCH QUESTIONS ADDRESSED
================================================================================

Q1: How well can topic modeling identify features/issues most associated 
    with negative product reviews?
    → Via impact_score = (prominence_in_negative × pct_negative_reviews)
    → Provides quantitative ranking of negative drivers

Q2: How do LDA and BERTopic differ when applied to the same dataset?
    → Direct comparison in COMPARISON_REPORT.txt
    → Coherence metrics, semantic grouping, sentiment analysis
    → Side-by-side visualizations

Q3: Is BERTopic more effective at grouping similar features and issues?
    → Qualitative assessment through semantic grouping evaluation
    → Keyword coherence analysis
    → Sentiment consistency comparison

Q4: How different are the conclusions reached using each model?
    → Quantitative metrics for model comparison
    → Top negative drivers identified by each model
    → Detailed analysis of differences and similarities
